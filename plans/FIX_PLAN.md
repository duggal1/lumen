# Backend reliability fix plan

Work in order on `fix/backend-reliability`, with one commit per verified package. Keep original media read-only, retain manual timeline decisions, and keep the existing shared rendering and offline mix. Preserve Classic and Loupe, aspect re-aim, motion blur, cursor smoothing, layouts and captions. Keep persisted settings decodable. No database, deployment or new UI system is involved.

| Package | Root-cause hypothesis | Approach, risk and acceptance |
| --- | --- | --- |
| QA harness | The current synchronous Metal benchmark renders a static timeline and ignores rejected submissions. Existing PNG comparisons measure regression against a prior render. | Add recorded click events through Director with a strict 60 Hz processing budget. Exercise the gate with a deliberate miss and compare the unchanged bench. Reuse timeline evaluation for pivot and stillness, existing Zoom tests for end release, GoldenHarness for text fixture comparison, and AudioCheck with recorded speech. Reject incomplete, invalid or unmeasured samples. Keep offscreen evidence separate from physical presentation. Run `make test` and both bench variants before progressing. |
| Auto zoom | The fixed preset is an explicit full-run zoom. Visual evidence and cursor-path steering require separate checks. Planner merges intent until hold or shot cap, then Camera can bridge the gap and continue beyond the last frames. | Record source-time segment counts and output-time arrival for idle, click, same-region burst, far click, typing, drag, wander and long sparse inputs. Require intent for event-triggered shots. Keep valid visual evidence and explicit presets. Bound release against a quiet window and the composition end. Preserve manual IDs and user suppression. Verify filtered Director fixtures and the full package gate. |
| Zoom motion | Separate camera springs for center and scale, cumulative follow movement and final-frame truncation can create drift or incomplete release. | Preserve the existing CameraTrack consumers and evaluate fixed-pivot log-scale eased legs from presentation time. Only move the anchor to keep an intentional subject visible. Verify 1,001+ samples in and out, monotonic bounded scale, endpoint stationarity, 0.5 px pivot residual and deterministic still camera. Check existing reframe and motion blur tests. |
| Playback performance | Synchronous decode-ahead, reader restarts, drawable acquisition, new upscale allocations and an audio-readiness wait on seek are possible stalls. | Profile real input, decode, encoding and presentation before choosing a change. Keep preview latest-wins and preserve the source-time selection across seeks and cuts. Check cold/warm, repeated seek and cancellation. Require a minute of 60 Hz click workload, p99 <16.6 ms, max ≤33 ms and zero dropped frames. Collect real presentation evidence independently of offscreen timings. |
| Crisp scaling | The crop compute pyramid crosses allocation thresholds and may resample twice. The shader also has a level-zero path and existing mip sampling. | Evaluate direct bicubic sampling in the shared compositor with existing mipmaps for minification. Use source-pixel alignment and preserve masks and Loupe. Run 2×/3×/4× text/UI golden comparisons against higher-resolution analytic geometry resolved at 2×, report SSIM gain and frame cost. Require the same click gate. |
| Studio Audio | Configuration branches change the mic chain, then program normalization may erase a voice gain change. Existing DeepFilterNet3 already provides on-device suppression. | Reuse the licensed bundled denoiser and existing fallback. Check baseline gain before deciding the final master approach. Use one offline high-pass, suppression, compression, tone and true-peak path for preview/export. Version cache keys when DSP changes and keep single-flight and cancellation semantics. Measure six recorded-speech variants, -16 LUFS, ≤-1 dBTP, clipping, measured noise reduction, presence and determinism. Flag baseline speech already above the target and preserve source audio, mute semantics and stored projects. |

Run `make build`, `make test`, the original and click render benchmarks, golden comparisons and `make verify` on the combined result. Confirm actual exported count and frame rate. Sign off each requested criterion and include exact display, capture-permission and listening commands where an interactive Mac is needed. Existing failures count as a red suite under the requested package gate.
