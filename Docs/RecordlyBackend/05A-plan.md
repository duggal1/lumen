# Backend 05A — coalesced CAS persistence
Base 39d43046b4638768ef38e6b0f72cd774daf85575. Part 5 of RECORDLY_BACKEND_PLAN.md. Existing ProjectSession enqueues every snapshot and obtains expected revision on the writer queue, so an older pending snapshot may adopt a new external revision after the editor reloads. One writer, one pending latest snapshot, 250 ms fixed cadence, per-ticket epoch, CAS against current own revision, conflict blocks until external timeline adopted. Explicit save and pending flush use same serial writer; ordinary write errors retain dirty snapshot and surface notice. Existing agent watcher is rechecked after local writes. Regression covers 1000 edits, conflict/adoption, disk failure/retry and explicit save superseding queued edits. UI close/export/share lifecycle flush wiring, active-write concurrency fault tests, versioned waveform and filmstrip services are remaining work. This patch does not touch Studio motion, keyboard, timeline view or renderer.
