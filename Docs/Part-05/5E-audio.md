# 5E — Audio mapping allocation and complexity (first slice)

The old mapper scanned every cut at each 48 kHz output sample and recomputed cut crossfade source anchors inside that loop. Precompute cut windows once and maintain an active chronological set per 1ms block, retaining original cut order for overlapping windows. Preserve cubic interpolation, ramp gain smoothing, equal-power crossfade and timing. The offline mixer accumulates directly into the destination stereo buffers rather than allocating a duration-sized mapped buffer per mic and two per system stem. A 1h mono mapped buffer alone is about 659 MiB, stereo about 1.29 GiB; these are nominal avoided intermediates, not measured peak RSS. Check cancellation before and during mapping, and before/after mastering. Existing whole-program DSP, master, source and SFX allocations remain; this is not yet a fully streaming audio pipeline. CI and real audio parity/latency measurements pending.
