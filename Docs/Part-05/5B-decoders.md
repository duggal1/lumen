# 5B — Independent reader state and byte-budgeted cache

The preview and video/GIF/cursor exports previously all read through the same stateful ProjectSession readers. Share only source-time mapping, not mutable AVAssetReader state. Export readers keep at most two decoded LRU entries per source, 32 MiB target, one active imported clip reader. Preview keeps up to eight entries with a 64 MiB budget for the primary source and up to two imported readers with smaller caches. The current frame survives even if it alone exceeds budget. These limits exclude decoder-owned surfaces, the lookahead frame and externally leased buffers, so they are not whole-process memory caps. Preserve VFR sample-and-hold and all formats. Test independent interleaved playback and cache bounds. Prefetch, memory-pressure eviction and actual M1 speed remain unverified.
