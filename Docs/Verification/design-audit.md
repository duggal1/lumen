## Verify (what “fixed” looks like)

1. **Library:** toggle and title on one 52pt baseline; content centered at 1280 and 1120; ledger values share one baseline, no shrink; Activity fits the card with no horizontal bleed; failed rows show badge + Retry only.
2. **Editor:** inspector ≥320 or controls shrink; `Captions` fully visible; no `Capti...`; Canvas/Pattern pickers fully inside card; timeline last label + playhead inset ≥4pt; zoom handles visible at 2.2×; Editor opens 1280×820 and enforces 960×640.
3. **Error:** no `AVFoundationErrorDomain`, no `-11829`, no `/Users/…` path in UI; two actions minimum.
4. **HUD:** panel size constant across countdown→recording; Stop never clipped.
5. **Backend:** `ffprobe` shows fragment headers on screen + webcam `.mov`; `engine.stop` signpost covers `videoQ` drain → `finishWriting`; `RecordingSession.start()` prompts Input Monitoring before `engine.start()`.
